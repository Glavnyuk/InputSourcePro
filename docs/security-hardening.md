# Виправлення безпеки імпорту та телеметрії

База: InputSourcePro 2.13.1, commit 6406b825b1d973271df13f02782836b215e29b3a.

- Імпорт через `inputsourcepro://import` завжди потребує підтвердження перед читанням і застосуванням налаштувань. У діалозі видно назву файлу; Cancel — дія за замовчуванням. `silent=1` приховує тільки повідомлення про успіх. Неінтерактивний імпорт через URL більше не підтримується.
- Імпорт з GUI та URL використовує одну блокіровку, щоб не запускати паралельні імпорти.
- Читання виконується поза головним потоком. Приймаються тільки звичайні локальні файли до 4 MiB; кінцеві символьні посилання, FIFO, пристрої та URL HTTP(S) відхиляються. Розмір перевіряється як перед читанням, так і під час нього. JSON декодується після обмеженого читання.
- URL-імпорт зупиняється, якщо backup поточних налаштувань не вдалося створити. Backup має унікальну назву і права 0600; новий каталог — 0700. Зберігаються десять останніх копій.
- Startup telemetry вимкнена за замовчуванням, вмикається тільки перемикачем Privacy → Share startup diagnostics. Цей вибір не входить до імпорту/експорту налаштувань. Вимкнення зупиняє майбутні startup-запити; вже надіслані дані не відкликаються. Feedback, Sparkle та рекламна іконка в налаштуваннях — окремі мережеві функції, описані в UI.

## Перевірка

- Xcode 27: build-for-testing з CODE_SIGNING_ALLOWED=NO і -onlyUsePackageVersionsFromResolvedFile — успішно.
- 27 XCTest: URL parsing, bounded file reader, FIFO, symlink, розмір 4 MiB/4 MiB+1, async read, telemetry opt-in persistence, діалог підтвердження та update channels — без помилок.
- Тести запускалися з окремим CFFIXED_USER_HOME. Дозволи Accessibility/Input Monitoring не надавалися.
- 25 Python-тестів release scripts — без помилок.
- plutil для всіх п'яти локалізацій і git diff --check — без помилок.

Не виконано ручне GUI QA, браузерний сценарій атаки end-to-end, перехоплення мережі чи перевірку готового підписаного DMG. Діалог перевірено XCTest на рівні кнопок/дії за замовчуванням, а не ручним кліком. Попередження компілятора в незмінених ділянках не виправлялися.

## Межі та встановлення

Не змінено Core Data schema, дозволи macOS, browser-rule semantics, signing identity або Sparkle update feed/key. Немає нових залежностей і release-публікацій. Production не зачеплено.

Це гілка для перевірки коду, не готовий незалежний реліз: feed/key Sparkle досі належать upstream. Перед розповсюдженням окремого форку потрібно визначити власний канал оновлень і signing identity, щоб upstream-оновлення не замінили виправлення. Для таких релізних змін потрібен окремий запит; приватні signing keys у репозиторій не додаються.

Відкат коду: revert коміту з цими змінами. Установленого застосунку чи production для відкату немає.
